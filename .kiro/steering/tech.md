# 기술 / 배포

## 스택

- 정적 HTML + CSS + 바닐라 JavaScript. 별도 프레임워크나 빌드 과정 없음.
- `index.html`은 화면, `app.js`는 로직, `styles.css`는 반응형 스타일을 맡습니다.
- `assets/`의 PNG 로고·아이콘·합동지방과 봉행자 한자 WOFF는 정적 파일입니다. 기존 외부 웹폰트도 사용합니다.
- 붓글씨 가로·세로 원본은 `wordmark-horizontal.png`, `wordmark-vertical.png`이며 `<picture>`로 760px 이하에서 세로를 선택합니다. 두 파일이 모두 읽혀야 적용하며 미확보 상태는 기존 `wordmark.png`로 표시합니다.
- 테스트는 Python Playwright + Chromium을 사용합니다. 실행 명령은 `python3 tests/browser_test.py`입니다.

## 저장과 로그인

- `app.js`의 `REMOTE` 객체가 Supabase 프로젝트와 공개 anon 키, `sangbogi` 테이블을 가리킵니다.
- 우선순위: Supabase → 호스트 `window.storage` → 브라우저 `localStorage`.
- `sangbogi`는 key-value 형태이며 `value`는 JSON 문자열입니다.
- 기존 월 기록 `sangbogi:cycle:<월>`은 초하루 데이터입니다. 명절은 `sangbogi:event:<월>:<id>`, 대체 승인은 `sangbogi:calendar:<월>`로 나눕니다.
- 가족은 클라이언트 PIN으로 확인합니다. 이메일 OTP 및 세션 토큰 갱신 요청을 제거했고 기존 브라우저 이메일 세션은 정리합니다.
- 사용자 요청에 따른 화면 잠금 수준이며, PIN이 서버의 인증 토큰을 발급하지는 않습니다. 현재 anon으로 분리된 테스트 키 저장·삭제를 확인했습니다.
- 손님 화면은 사적 준비 내용을 DOM에 생성하지 않습니다. 공개 API 접근 정책까지 바꾸는 변경은 아닙니다.
- 목록·메모·직접 입력한 출처와 성함은 입력 즉시 해당 상의 로컬 기록에 반영합니다. 저장은 기존 400ms 묶음 처리를 사용하고, 저장 중 추가 수정은 다음 저장까지 유지합니다.
- 입력 중인 목록은 저장 완료·12초 자동 갱신 때 DOM을 교체하지 않습니다. 포커스·선택 범위·한글 조합을 유지하며 포커스 이동 후 갱신합니다. 다른 월/행사나 손님 화면으로 바꾸면 이 보호를 적용하지 않습니다.
- 입력 이력은 저장·포커스 이동·다른 수정 전에 항목별로 묶어 확정합니다. 한글 조합 중에는 새 저장을 시작하지 않으며, 기록은 작성 당시 월과 작성자에 귀속됩니다.
- 상달 초하루의 불사단지 쌀 교체는 기존 `cycle.part['bulsa-rice']`에 `stamp`와 `bindCycleWriter`로 저장합니다. 새 테이블·마이그레이션 없이 초하루 월/연도 키에 귀속됩니다.
- 밥공양은 `cycle.part`의 `rice-offering-sodang`, `rice-offering-jungdang`, `rice-offering-yukdang`, `rice-offering-geollip`에 같은 방식으로 월별 저장합니다. 기존 생쌀·구매 기록에서 완료를 추정하거나 값을 옮기지 않습니다.
- 12초 주기 및 화면 복귀 갱신은 택일과 월별 승인을 함께 읽습니다. 택일 저장 중 조회와 이전 조회 응답은 새 저장을 덮어쓰지 않습니다.

## 실데이터 주의

- 실데이터가 있습니다. 기존 키·값을 초기화하거나 명절 키로 복사하지 마세요.
- 구월 초하루의 기존 자료는 기존 키 그대로 표시합니다. 예전 명절 이름 완료 표시도 초하루에서 읽기 호환합니다.
- 명절 상 내용이 정해지지 않았으면 초하루의 품목과 차례를 자동으로 가져오지 않습니다.
- 테스트는 합성 응답을 사용합니다. 실제 저장 확인이 필요하면 기존 기록과 겹치지 않는 고유 테스트 키만 사용하고 검사 후 정확히 그 키만 삭제합니다.

## 중양 전용 준비 (2026-10-21 갱신)

- 중양 기본 준비 7항목·진행안 2개는 기존 명절 키의 `cycle.part`에 `jungyang-*` 이름으로 저장합니다. 새 테이블·실데이터 이관·로그인 변경은 없으며, 기본 7항목만 별도 집계하고 완료는 `done:jungyang`에 기록합니다.
- 제거한 권장 체크 `jungyang-water/light/fruit`와 통합 전 `jungyang-prayer-ancestors/peace`는 저장된 값·작성자·시각을 지우거나 다른 항목으로 옮기지 않습니다. `JUNGYANG_LEGACY_LABELS`로 과거 이력 이름을 유지합니다. 새 통합 체크 `jungyang-prayer-ancestors-peace`는 이전 완료 상태에서 값을 추정하지 않습니다.
- `JUNGYANG_SERVICE_RECORDS[2026]`은 사용자 보고의 완료·보고일(`2026-10-21`)·술과 식혜(후추차) 자리를 담은 읽기 전용 상수입니다. `jungyang-cups-card`는 2026년 가족 중양에서만 만들고 기본 품목·미래 템플릿·DB 체크를 자동으로 바꾸지 않습니다.
- 합동지방은 image_gen으로 제작한 정적 PNG `assets/jungyang-jibang-s25-ultra.png`입니다. 실제 크기는 853×1844, 약 6:13의 세로 비율로 S25 울트라에서 비율을 유지해 표시합니다. PNG·`jibang.html`을 HTML·JS·CSS와 함께 배포합니다. 새 이미지 라이브러리나 외부 런타임 의존성은 없습니다.
- `jibang.html`은 사용자 버튼 동작으로 Fullscreen API를 요청하고 `object-fit:contain`을 유지합니다. 설정 숨기기·다시 열기, 미지원 시 PNG 저장 안내가 있습니다.
- 축문은 `維歲次 丙午 九月九日`과 같이 한문으로 표시하고, 한문 봉행자 `JUNGYANG_CELEBRANT`는 `恩熩堂 金炯錫`으로 고정합니다. 안내·독음·해석은 `은호당 김형석`으로 표시합니다. 선택 음력 연도의 표준 60갑자 연간지를 한문·독음·해석에 연동하며(2026년 丙午/병오, 2027년 丁未/정미), 검증되지 않은 삭간지·일진을 임의로 추가하지 않습니다.
- `JUNGYANG_CHUKMUN`은 한문·한국식 독음·뜻풀이의 14개 묶음과 문단 구분용 `null`의 배열입니다. `jungyangChukmunLines()`가 세 줄의 간지를 함께 치환하며, 각 `lang="lzh"` 한문 행 아래 `lang="ko"` 13px 독음과 작은 구절별 뜻풀이를 표시합니다. 별도의 긴 해석 상수·패널은 제거했습니다. `重陽復至`의 독음은 ‘중양부지’, `祖先`은 ‘조선’이며 뜻풀이의 ‘조상’과 구분합니다.
- TXT도 각 구절을 한문 한 줄·독음 한 줄·뜻풀이 한 줄 순서로 담아 로컬 Blob으로 내려받고 서버에 저장하지 않습니다.
- `pickIndexRespectingDone()`는 첫 진입·재로그인에서만 현재 정규 음력 구월의 중양 완료를 읽고 같은 해 시월 초하루를 고릅니다. 중양 명절 키의 원격 자료와 로컬 수정을 병합하되 해당 키가 저장 대기 중이면 로컬 값을 우선합니다. 구월 초하루만 끝난 상태로는 중양을 건너뛰지 않으며, 수동 월 이동·12초 갱신은 현재 열람 위치를 유지합니다.
- `jungyangCompletionRecord()`는 직접 저장한 `done:jungyang`과 2026년 완료 보고를 판정합니다. 서울 날짜로 보고일 이전에는 보고를 적용하지 않고, 보고일 당일·이후의 명시적 취소는 보고보다 우선합니다. 시각이 없거나 유효하지 않은 직접 기록도 임의로 덮어쓰지 않습니다. 다른 연도는 직접 `done:jungyang` 상태를 사용합니다. 보고를 표시하거나 초기 월을 선택하는 것만으로 원격 기록을 새로 쓰지 않습니다.
- `renderDone()`에서 중양 완료를 새로 켜면 해당 중양 키에 저장 대기 수정을 남기고 시월 초하루로 이동합니다. 완료를 끄는 동작은 이동하지 않습니다.
- 봉행자의 `恩熩堂金炯錫` 여섯 글자는 로컬 `assets/fonts/eunhodang-hanja.woff`로 제공합니다. 환경에 설치된 Noto Serif CJK KR Regular 2.003 한국어 글꼴에서 fontTools로 추출한 5,932바이트 서브셋이며 `熩` U+71A9를 포함합니다. 파생 이름은 **Eunhodang Hanja**, 라이선스는 OFL 1.1이고 `OFL.txt`·`SOURCE.md`를 함께 배포합니다. 제작에 새 패키지 설치·글꼴 다운로드는 없었습니다. 과거 Google 웹폰트 서브셋의 문자 범위를 전체 Noto CJK의 범위와 혼동하지 않습니다.
- `@font-face`의 여섯 글자 `unicode-range`와 한문 본문 첫 글꼴 지정으로 필요한 한자만 로컬 WOFF를 사용합니다. 글꼴의 원본·서브셋 해시와 저작권·제작 정보는 `assets/fonts/SOURCE.md`에 기록합니다.

## 자료 기반 상차림 확장 (2026-10-23)
- rituals.js를 HTML·app.js·styles.css와 함께 배포해야 합니다. 새 서버·테이블·마이그레이션은 없습니다. 새 part 이름은 ritual-행사id-항목id이며 기존 이벤트 키를 그대로 씁니다. 같은 상에서 펼친 자료 설명은 갱신 때 열림 상태를 유지합니다.
- 의존성 없는 도메인 검사와 합성 Supabase를 쓰는 Python Playwright 회귀검사를 유지합니다. 테스트용 브라우저·패키지는 공개 저장소에 포함하지 않습니다.
