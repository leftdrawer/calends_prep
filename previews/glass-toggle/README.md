# 유리 밝기 스위치 미리보기

- 주소: `https://leftdrawer.github.io/calends_prep/previews/glass-toggle/`
- 운영 루트의 `index.html`, `styles.css`, `theme-toggle.js`, `app.js`는 바꾸지 않습니다. 사용자 외관 확인 전에는 앱에 연결하지 않습니다.
- 애플리케이션 API, 가족 로그인, 실제 준비 기록을 가져오지 않습니다. 같은 공개 로고 파일만 참조합니다.
- 저장은 `calends:glass-preview:theme` 한 키뿐입니다. `sangbogi:*`는 읽지도 쓰지도 않습니다.

## 표현 방식

원본은 WebGL 조각 셰이더입니다. 이 미리보기는 원본 코드를 복제하지 않고 SVG·CSS 층으로 다시 구성했습니다.

- 투명한 버튼 → 반투명 트랙 → SVG 픽셀 도안 → CSS 유리 렌즈/테두리 순서입니다. 캔버스를 사용하지 않으므로 캔버스 전체가 흰 사각형으로 합성되는 경로는 없습니다.
- 244×108px 영역에 72×72px 렌즈를 놓습니다. 휴대폰/DPR에 따라 축소하지 않습니다.
- 해·달은 검토 가능한 11×11 문자 도안입니다. 점을 각도순으로 짝지어 움직이고, 정지 상태에서는 정확히 도안으로 돌아옵니다. 중간에서 끌기를 멈추면 점 위치도 멈춥니다.
- 실제 DOM 바탕은 렌즈의 `backdrop-filter`를 통해 이어집니다. 문양의 약한 확대/가장자리 위치 변화는 수식으로 흉내 냅니다. 원본과 동등한 광학 굴절·레이 트레이싱을 구현했다고 주장하지 않습니다.
- 아래/위로 이동하는 이중 빛 띠, 바깥 광륜, 색이 갈라지는 테두리, 마우스를 따르는 작은 반사광을 따로 합성합니다. 전환 중에는 픽셀 소용돌이와 두 색의 테가 강해지지만 멈추면 정확한 문양으로 돌아옵니다. 렌즈 전체를 흰색으로 채우지 않습니다.
- 빠른 재클릭은 현재 위치/속도에서 방향을 바꿉니다. 안정되면 RAF를 멈춥니다. 모션 줄이기는 즉시 전환, 투명도 줄이기는 단색 렌즈로 대체합니다.

## 확인

`python tests/glass_preview_test.py` (기존 브라우저 회귀 검사와 동일한 Playwright/Pillow 환경).

기능 검사에는 화면 이미지 캡처가 없습니다. DOM 크기, 도안의 점 좌표, CSS 알파, 상태·저장·네트워크 경계를 검사합니다. 이 검사는 실제 외관의 아름다움이나 원본과의 시각적 동등성을 증명하지 않습니다.

미리보기의 '두 상태와 투명 배경 확인'을 열면 밝은/어두운 정지 상태와 단색/격자/대비 줄무늬를 직접 비교할 수 있습니다.
