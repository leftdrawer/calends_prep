# 카페 자료 기반 상차림 1차 반영

관찰·적용 기준일: 2026-10-23. 세 카페 전체를 읽었다는 보고가 아닙니다.

## 1. 이번에 옮기는 것

- 추석: 이미 사용자 기준으로 확인된 만연당의 법도를 체크 가능한 준비안으로 구체화합니다. 삼당 송편·밥·토란국, 건립 몫, 조상 차례상 여부 확인을 구분합니다.
- 칠석: 스승니임ㅡ서울의 2026년 최신 자료에 근거한 준비안입니다. 공양 일곱 그릇, 대추 일곱 개 백설기, 증편·동자떡·계절나물·제철과일·술의 몫을 설명합니다. 증편 반 말/한 말은 신도 규모를 전제로 한 예시이지 은호당의 고정 주문량이 아닙니다.
- 영등맞이: 지역과 형편에 맞춘 기본 예시를 확인하는 준비안입니다. 별도 제상을 반드시 새로 만드는 것으로 정하지 않으며 생선 몫은 먼저 자신의 법도와 확인합니다.
- 동지: 달빛도령의 팥죽·비손 답변을 기본으로 날짜·절입시각 확인, 신당 청소, 팥죽 준비와 비손을 구분합니다. 그릇 수는 회원이 정리한 수치를 스승의 확정 지침으로 승격하지 않습니다.
- 정월·영등달·상달 초하루: 기존 초하루 품목과 체크를 바꾸지 않고 그 달의 자료 설명을 덧붙입니다. 특히 시월 불사단지 쌀 교체는 기존 항목을 유지합니다.
- 홍수맥이·삼신날·초파일·오월 선택 행사·백중·성주맞이·삼재풀이는 자료의 적용 범위와 아직 정할 내용을 읽기 안내로 제공합니다. 근거가 부족한 필수 체크나 제물 수량을 만들지 않습니다.

## 2. 합치지 않은 차이

- **계보 차이:** 만연당의 2026년 추석 글은 상차림 후 약 두 시간, 스승니임의 2026년 진행안은 행사 후 약 30분의 흠향을 설명합니다. 기산점과 방식이 다르므로 같은 철상 규칙으로 합치지 않습니다.
- **조건·시점 차이:** 만연당의 2024년 명절 글은 가중의 제사 상황에 따른 세/여섯 공기를 구분하고, 2026년 추석 글은 제자의 여섯 공기를 설명합니다. 가족 상황을 추정해 자동으로 수량을 계산하지 않습니다.
- **평소 차림의 차이:** 2024년 영등 설명은 과일 다섯→셋, 전 일곱→다섯의 예시입니다. 2026년 직접 답변은 과일 다섯→셋, 전 다섯→셋입니다. 최신 답변을 안내하되 기존 입력·체크·과거 기록은 지우지 않습니다.
- **다른 의례:** 출산·유산 맥락의 ‘삼신풀이’ 제물을 연중 ‘삼신날’의 확정 제물로 복사하지 않습니다. 이 자료의 산후 음식 설명도 의학적 사실이나 유산의 도덕적 책임으로 안내하지 않습니다.
- **다른 대상:** 칠석 준비안의 밥 일곱 그릇과 사용자 확정 중양의 총 다섯 공기는 서로 다른 행사입니다. 중양의 좁은 신당 절충안을 모든 행사에 자동 복사하지 않습니다.
- **시행 여부:** 백중·초파일의 시행 여부는 작성자별로 다릅니다. 카페 글만으로 기존 행사 탭을 삭제·완료하거나 사용자 기준을 대신 결정하지 않습니다.
- **현재 연도:** 2019년 동지 글의 절입시각, 2023년 글의 ‘올해 애동지’라는 정정은 당시 설명입니다. 당해 연도의 시각·종류로 복사하지 않습니다.

## 3. 출처와 판정 방식

공개 페이지가 사용하는 제목·작성자·날짜·URL은 `rituals.js`의 `RITUAL_LIBRARY.sources`에 모읍니다. 체크 항목, 설명, 법도 차이, 출처 참조를 데이터로 분리하여 같은 원문을 여러 화면에서 반복 복제하지 않습니다.

주요 근거:
- 애동제자 길라잡이 2173·2174: 만연당의 추석 설명과 사진의 명시적 캡션. 사진 속 접시 개수를 추정한 수량은 채택하지 않음.
- 같은 카페 1952·2051: 영등달 간소화, 소당 과일·철상에 관한 만연당의 직접 답변.
- 같은 카페 1073·1195: 동지에 관한 달빛도령 답변과 회원 정리의 구분. 1195의 모든 수량을 매니저가 승인했다고 보지 않음.
- 만신100년의비밀 176·204·329·112: 차례와 굿상의 몫, 영등달, 삼재 준비, 신령과 조상상의 구분. 329의 예단 적용 단위와 색은 확정하지 않음.
- 올바른 무당되기 27997·26404·16119: 칠석 최신 안내와 영등상의 예시·장소.
- 같은 카페 15906·15940·19501·26689: 동지, 현대도시 횡수막이, 지역별 안택 소개, 고사와 큰굿의 순서 구분.
- 같은 카페 15033·24924·26992·27221·27222·14196·25391·19604·25431·28159: 연중 행사 적용 범위, 별도 의례·축원·세시풍속·다른 계보의 설명.

회원 전용 원문·댓글·사진의 전수 사본, 개인 상담 사연과 신도 개인정보는 공개 저장소에 넣지 않습니다. 비공개 조사 색인은 작업 계정의 별도 연구 폴더에 보관합니다. 앱에는 필요한 요약과 출처 링크만 제공합니다.

## 4. 안전과 기록

- 임의 소각, 길·산·하천에 제물이나 팥물 버리기, 칼 던지기 등을 일상 상차림의 자동 체크 절차로 만들지 않습니다. 허용된 시설·지역 규정과 음식 위생을 우선합니다.

- 새 준비·진행안은 해당 행사 `part`의 `ritual-<행사 id>-...`에 작성자·시각과 함께 저장합니다. 자료 열람·설명 펼침은 저장을 만들지 않습니다.
- 손님에게 새 준비안·자료 링크·가족 체크 DOM을 만들지 않습니다.
