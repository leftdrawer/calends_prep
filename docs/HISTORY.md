- **무엇**:

## 배경 사실 (변하지 않는 것들)
- 앱은 원래 Netlify + Supabase 조합으로 운영되고 있었다.
- `index.html` 안에 이미 "깃허브 페이지로 옮길 때 REMOTE 세 줄만 채우면 된다"는 주석이 있어,
  제작자가 처음부터 이전을 염두에 두고 만들었다.
- 데이터는 화면과 분리되어 Supabase에 저장되므로, 배포 위치를 바꿔도 기록은 안전하다.
